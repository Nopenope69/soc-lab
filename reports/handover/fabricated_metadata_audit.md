# Fabricated Dataset Metadata Audit & Remediation Report

## 1. Executive Summary

This report documents the comprehensive audit and remediation of dataset provenance metadata across `soc-lab`. 

Six manifests previously present in `data/manifests/` were discovered to contain fabricated placeholder hashes (e.g. empty SHA-256 `e3b0c442...`, zero-padded empty MD5 `d41d8cd9...`, sequential patterns `0123456789abcdef...`, `1234567890abcdef...`, `11223344...`, `aa11bb22...`, and repeating hex patterns `a1b2c3d4...`, `f0e1d2c3...`), invented file names (`metadata.json`, `pev_secondary_use_cells_manifest.csv`, `data/cell_01_cycling.csv`, `README_dataset5.txt`, `test_condition_matrix.csv`, `README.md`, `cell_specifications.json`, `profile_wltp_current.csv`), invented titles, and invented identifiers (e.g. Portland State DOIs `10.15760/reil_datasets/1` and `10.15760/reil_datasets/5`, fake Zenodo DOI `10.5281/zenodo.20813753`, and fake Recherche Data Gouv URL `https://doi.org/10.57745/OLBXKT`). For CALCE, the uncommitted header had DOI `10.1016/j.jpowsour.2013.03.111`, which resolves to an unrelated fuel-cell electrode paper.

All six fabricated manifests were moved to `data/manifests/_quarantine_fabricated/` and replaced with truthful manifests generated directly from real files on disk (or explicit `NOT_DOWNLOADED` stub manifests). The `calce_a123.sha256` manifest was audited against disk (52/52 files verified); its 52 file hash lines were strictly preserved, and only its header comment lines were corrected.

## 3. Strict Verification & Integrity Guarantees

1. **Zero Placeholder Hashes in Production:** All production manifests in `data/manifests/` contain strictly SHA-256 hashes computed from physical files present on disk.
2. **Audit Tooling:** Running `scripts/verify_datasets.py` scans every manifest entry against `is_fabricated_hash()`. Any attempt to introduce synthetic or placeholder hashes instantly flags the dataset as `FABRICATED` and exits with an error.
3. **No Algorithm or Frozen File Drift:** No changes were made to any frozen estimator, scenario, or historical report.
