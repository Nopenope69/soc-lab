# SOH Estimation Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver Phase 1 of the SOH Estimation Subsystem: data contracts, cell reference protocols, dataset loaders, ground-truth generation ($SOH_C$ and $SOH_R$), conventional baseline model, and benchmarking test harness, while maintaining 100% regression compatibility with the existing SOC lab.

**Architecture:** A modular Python package in `src/soh/` decoupled from `src/soc/`. Implements physical cell reference protocols, separate $SOH_C$ and $SOH_R$ ground-truth metrics, feature quality and window eligibility checks, a dedicated degradation modeling module, a standardized `SohEstimator` ABC, a regularized baseline model, and uncertainty metrics (PICP, MPIW, Winkler score) with grouped battery-level splits.

**Tech Stack:** Python 3.14, NumPy, SciPy, Pandas, Scikit-learn, Pydantic, PyTest.

**Spec:** [docs/internal/specs/2026-11-15-soh-estimation-design.md](../../../../../../../../docs/internal/specs/2026-11-15-soh-estimation-design.md)

## Global Constraints

- Current Polarity: $I > 0$ is discharge, $I < 0$ is charge, $I = 0$ is rest (matches `src/soc/models/cell_2rc.py`).
- Canonical Units: Voltage in V, Current in A, Time in s, Temperature in °C, Capacity in Ah, Resistance in $\Omega$.
- SOH State Variables: Separate $SOH_C$ (rated & BOL-relative) and $SOH_R$ (rated & BOL-relative).
- Do not hardcode universal cutoff voltages or rates; all protocols must use configurable `CellReferenceSpec`.
- Partial-charge windows must support returning `EstimationStatus.INSUFFICIENT_INFORMATION`.
- Grouped battery-level cross-validation (zero data leakage across physical cells).
- Zero modifications to existing `src/soc/` code. All existing SOC tests must continue to pass.

## File Structure

- `requirements.txt`: Pin `scikit-learn>=1.9.1`.
- `src/soh/__init__.py`: Package entry and version.
- `src/soh/common/`:
  - `units.py`: Polarity, canonical units, conversions.
  - `protocols.py`: `CellReferenceSpec` and reference test protocols.
  - `contracts.py`: Pydantic / dataclass schemas (`Measurement`, `CycleRecord`, `SOHState`, `FeatureQualityRecord`, `SohEstimate`, `EstimationStatus`).
  - `eligibility.py`: Window eligibility rules and criteria.
- `src/soh/degradation/`:
  - `mechanisms.py`: Calibrated SEI solvent diffusion growth kinetics, LLI, and empirical aging.
  - `reversible.py`: Temperature Arrhenius resistance scaling and relaxation adjustment.
- `src/soh/data/`:
  - `base_loader.py`: `SohDataset` and abstract `AgingDataLoader`.
  - `synthetic_aging.py`: Parametric synthetic aging generator with reference protocol verification.
  - `calce_aging.py`: Real CALCE cycle parser with ground-truth calculation.
  - `window_extractor.py`: Window extraction with eligibility gating.
- `src/soh/estimators/`:
  - `base.py`: `SohEstimator` ABC and `SupportsEmbeddedExport` protocol.
  - `baseline_ridge.py`: Conventional regularized Ridge regression baseline with prediction intervals.
- `src/soh/benchmarks/`:
  - `metrics.py`: RMSE, MAE, MaxError, 95th-pct, PICP, MPIW, Winkler score.
  - `split_runner.py`: Grouped leave-one-battery-out evaluation runner.
  - `report.py`: Markdown / CSV report generator.
- `scripts/run_soh_phase1.py`: Phase 1 runner script.
- `tests/soh/`:
  - `test_common.py`: Units, contracts, protocols, eligibility.
  - `test_degradation.py`: Degradation kinetics and reversible temperature scaling.
  - `test_data_loaders.py`: Synthetic generator and CALCE parser.
  - `test_baseline_estimator.py`: Ridge baseline fit and prediction intervals.
  - `test_benchmarks.py`: Grouped battery splits and uncertainty metrics.
